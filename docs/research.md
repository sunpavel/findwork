# Исследование: источники, инструменты, что подключать

Дата: июнь 2026. Все факты ниже проверены (где возможно — эмпирически).

## Источники вакансий

| Источник | Доступ | Легальность | Под профиль (Москва, C-level, 600–900к) | Статус |
|----------|--------|-------------|------------------------------------------|--------|
| **HH.ru** | [Официальный API (OAuth2)](https://api.hh.ru/openapi/redoc), своё приложение на dev.hh.ru | ✅ легально | 🟢 основной (там вся ЦА вакансий) | ✅ **реализован** (нужны ключи) |
| **Vacancy.ru** | уточняется (какой именно сайт) | — | 🟡 по профилю | уточнить у кандидата |
| **Хабр Карьера** | парсинг публичной выдачи | публичные данные | 🟡 IT-роли, есть директорские | кандидат на подключение |
| **getmatch** | TG-бот, публичная выдача (зарплаты открыты) | публичные данные | 🟡 IT, зарплаты видны | кандидат |
| **Telegram-каналы вакансий** | Telegram API / парсинг | публичные данные | 🟡 точечно топ-роли | кандидат |
| **Trudvsem («Работа России»)** | [открытый API](https://trudvsem.ru/opendata/api), бесплатно | ✅ легально | ⚪ в основном регионы — кандидат отказался | отключён по запросу |

**Проверено (июнь 2026):** `dev.hh.ru` → `200` (регистрация приложений открыта);
`POST api.hh.ru/token` с фейковыми ключами → корректная ошибка `invalid_client` (эндпоинт жив);
анонимный `GET api.hh.ru/vacancies` → `403` (с токеном — работает, см. доку get-vacancies).

**Вывод по источникам:** HH подключается **официально и легально** через своё приложение
(OAuth2) — это основной источник. Эмуляция/обход не нужны. Vacancy.ru — уточнить, что за сайт.
Хабр Карьера/getmatch/TG-каналы — следующие кандидаты для расширения охвата. Trudvsem отключён
по просьбе кандидата. Подробности по HH — в [hh_api.md](hh_api.md).

## Инструменты автоматизации (условно бесплатные)

| Инструмент | Что даёт | Стоимость | Рекомендация |
|------------|----------|-----------|--------------|
| **Python-ядро (наше)** | скоринг, пайплайн, источники, Telegram | бесплатно | ✅ основа — уже есть |
| **n8n** (self-hosted) | визуальные воркфлоу, 280+ готовых шаблонов, есть job-search + Telegram + LLM | бесплатно на своём VPS | 🔵 опц. поверх ядра, если захочется «без кода» |
| **Официальный HH API (OAuth2)** | поиск, резюме, отклики (`/negotiations`) | бесплатно | ✅ основной путь для HH |
| **BeautifulSoup / Scrapy** | парсинг HTML (Хабр, getmatch, каналы) | бесплатно | для новых источников |
| **Playwright** | эмуляция браузера | бесплатно | только как fallback, если понадобится |
| **SerpAPI** | Google Jobs агрегатор | free tier ~100/мес | опц. расширение |

## Анализ / LLM (для доскоринга и сопроводительных)

| Вариант | Плюсы | Стоимость | Рекомендация |
|---------|-------|-----------|--------------|
| **Claude API (Anthropic)** | лучшее качество текста и матчинга, tool use | платно по токенам (дёшево на наш объём) | ✅ для адаптации резюме/писем и доскоринга |
| **Локальная модель (Ollama)** | бесплатно, приватно | нужен ресурс на сервере | 🔵 если важна нулевая стоимость |
| **Без LLM (шаблоны)** | бесплатно, детерминированно | ниже качество | fallback в `tailor.py` |

> Ядро `relevance.py` уже без LLM даёт осмысленный скор. LLM добавляем как **доскоринг**
> (тонкая семантика поверх ключевых слов) и для **генерации сопроводительных** — там качество
> текста решает.

## Лучшие практики 2026 (из обзоров рынка)

- **Human-in-the-loop:** не отправлять отклики без подтверждения — уведомление в Telegram с
  кнопкой «Одобрить». (Совпадает с нашим выбранным режимом.)
- **Анти-робот:** рекрутеры различают шаблонный AI-текст → добавлять «шероховатости», личную
  специфику, не слать одинаковые письма.
- **Вежливые лимиты:** паузы между действиями, дневной лимit откликов (~ десятки, не сотни),
  чтобы не ловить бан и не выглядеть спамом.
- **Соблюдение ToS:** приоритет легальным источникам (Trudvsem, публичные выдачи); серый путь —
  осознанно и аккуратно.

## Что подключить (приоритеты)

1. **Сейчас, бесплатно, легально:** Trudvsem — ✅ сделано.
2. **После VPS:** боевой HH-источник (на базе `hh-applicant-tool`) — основной охват.
3. **Расширение охвата:** парсеры Хабр Карьера + getmatch + 2–3 Telegram-канала.
4. **Качество:** Claude API для доскоринга и сопроводительных (нужен ключ в `.env`).
5. **Опционально:** n8n на том же VPS — если захочется визуально собирать сценарии.
