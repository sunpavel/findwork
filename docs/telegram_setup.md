# Настройка Telegram-бота для дайджеста

Займёт ~5 минут. Токен и chat_id потом положим в `.env` на VPS (не в репозиторий!).

## 1. Создать бота

1. Открой в Telegram чат с **@BotFather**.
2. Отправь `/newbot`.
3. Имя бота — любое (напр. `Pavel Jobs`).
4. Username — должен заканчиваться на `bot` (напр. `pavel_findwork_bot`).
5. BotFather пришлёт строку вида:
   ```
   123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
   Это **TG_BOT_TOKEN**. Никому не показывай и не коммить в git.

## 2. Узнать свой chat_id

1. Найди только что созданного бота по его username и нажми **Start** (или напиши ему «привет»).
2. Открой в браузере (подставь свой токен):
   ```
   https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates
   ```
3. В ответе найди `"chat":{"id":123456789,...}` — это число и есть **TG_CHAT_ID**.
   - Если `getUpdates` пустой — сначала напиши боту любое сообщение и обнови страницу.

## 3. Проверить

На машине, где лежит проект:

```bash
export TG_BOT_TOKEN="123456789:AAE..."
export TG_CHAT_ID="123456789"
python3 src/notify.py "проверка связи findwork"
```

Если в Telegram пришло сообщение — всё готово. Дальше эти переменные пропишем в `.env`
(см. `.env.example`) на VPS, и пайплайн будет слать дайджест автоматически.

> Безопасность: токен даёт полный контроль над ботом. Храни его только в `.env`
> (файл уже в `.gitignore`). Если токен утёк — в @BotFather командой `/revoke` выпусти новый.
