# Приём заявок с сайта → Telegram-бот (Yandex Cloud Function)

Токен бота **не хранится на сайте** — он живёт в переменной окружения облачной функции.
Сайт отправляет заявку на URL функции, функция шлёт её тебе в Telegram.

Код функции: [`serverless/yc-lead-bot/index.js`](../serverless/yc-lead-bot/index.js)

## Шаг 0. Перевыпусти токен (он засветился в чате)
@BotFather → `/revoke` → выбери @SkvortsovADV_bot → получишь **новый токен**. Его и используем.

## Шаг 1. Узнать chat_id
Напиши `/start` боту **@SkvortsovADV_bot** — я заберу твой `chat_id` и пришлю (или открой
`https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найди `"chat":{"id": ... }`).

## Шаг 2. Создать функцию в Yandex Cloud
1. Зайди в консоль: <https://console.yandex.cloud/> → сервис **Cloud Functions** → **Создать функцию**.
   (Если нет платёжного аккаунта — создай, есть бесплатный грант; бесплатного тарифа на форму хватит с запасом.)
2. Имя: `lead-bot`. Создай.
3. **Создать редактор / версию:**
   - Среда выполнения (Runtime): **Node.js 18** (или новее).
   - Способ: «Редактор кода». Файл `index.js` — вставь содержимое
     [`serverless/yc-lead-bot/index.js`](../serverless/yc-lead-bot/index.js).
   - **Точка входа:** `index.handler`
   - Таймаут: `10` сек, память: `128 МБ`.
4. **Переменные окружения** (раздел «Переменные окружения»):
   ```
   TG_TOKEN     = <новый токен от BotFather>
   TG_CHAT_ID   = <твой chat_id из шага 1>
   ALLOW_ORIGIN = https://skvortsovadv.ru
   ```
5. Нажми **Создать версию**.

## Шаг 3. Сделать функцию публичной
В функции → вкладка **«Обзор»** → включи **«Публичная функция»** (Public function).
Скопируй **ссылку для вызова** вида:
```
https://functions.yandexcloud.net/d4xxxxxxxxxxxxxxxxx
```

## Шаг 4. Подключить к форме
Пришли мне эту ссылку — я впишу её в форму (`LEAD_WEBHOOK_URL` в `script.js`) и задеплою.
После этого заявки с сайта будут приходить тебе в Telegram.

## Проверка
Отправь тестовую заявку с сайта → в Telegram от @SkvortsovADV_bot придёт сообщение с данными.

---
**Безопасность:** токен — только в переменных окружения функции, в коде сайта его нет.
`ALLOW_ORIGIN` ограничивает приём только с твоего домена. Заявки (ПДн) идут напрямую
тебе в Telegram, без посредников.
