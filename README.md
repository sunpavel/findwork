# findwork — система поиска работы для Павла Скворцова

Цель: автоматизировать поиск работы на позиции **CMO / CCO / Growth**:

1. 🔍 собирать новые вакансии по профилю;
2. 📨 утром присылать дайджест релевантных вакансий в Telegram;
3. 📝 генерировать резюме/сопроводительное под конкретную вакансию;
4. ✅ откликаться на релевантные (с подтверждением или авто — по выбору).

## ⚠️ Важная реальность: HH.ru закрыл публичный API для соискателей (15.12.2025)

Проверено эмпирически (июнь 2026): запрос к `api.hh.ru/vacancies` отдаёт `403 forbidden`
даже с корректным `User-Agent`. Официальный путь (OAuth-приложение → поиск/резюме/отклики)
для соискательских сервисов больше недоступен.

Рабочие, но **«серые»** обходные пути (оба нарушают ToS HH, есть риск блокировки аккаунта):

- **Эмуляция официального Android-приложения HH** (как `s3rgeym/hh-applicant-tool`).
- **Эмуляция браузера** (Playwright: логин по SMS, клики, капча вручную).

> Поэтому массовый автоотклик и автосоздание резюме на HH — это обход защиты с реальным
> риском бана. Подход к риску выбирает кандидат (см. «Открытые решения»). По умолчанию
> рекомендуется human-in-the-loop: бот предлагает — кандидат подтверждает.

## Решения (зафиксированы с кандидатом)

- **Подход к HH-риску:** полу-авто с подтверждением (бот предлагает → кандидат жмёт «OK»).
- **Хостинг:** свой VPS в РФ (резидентный IP для стабильной работы с HH).
- **Канал:** Telegram-бот (создаём — см. `docs/telegram_setup.md`).
- **Профиль поиска:** CMO / CCO / Growth · 600–900к ₽ · формат неважно · акцент на матчинг релевантности.

## План по фазам

- **Фаза 0 — фундамент** ✅ *(сделано)*
  - Профиль и веса навыков — `profile/profile.json` (+ `profile.md`).
  - Эталонное резюме — `resume/master_cco.md`.
  - Ядро скоринга — `src/relevance.py` (без зависимостей, с демо).
- **Фаза 1 — сбор вакансий + утренний дайджест в Telegram** 🚧 *(пайплайн готов, нужен боевой источник)*
  - ✅ Пайплайн `src/pipeline.py`: источник → дедуп → скоринг → дайджест в Telegram.
  - ✅ Отправка в Telegram `src/notify.py`; тестовый источник `sample` гоняется офлайн.
  - ⏳ Боевой источник `hh` — подключается на VPS после авторизации (`src/sources.py`).
- **Фаза 2 — полу-автоотклик с подтверждением** (средний риск) — *далее*
  - Кнопки в боте: «Резюме под вакансию» (адаптация) / «Откликнуться» / «Пропустить».
- **Фаза 3 — полный автоотклик по порогу** (макс. риск) — только по явному согласию.

## Запуск

```bash
python3 src/relevance.py                          # демо скоринга
python3 src/pipeline.py --source sample --dry-run  # дайджест на тестовых вакансиях (без отправки)
python3 src/pipeline.py --source sample --send     # отправить тестовый дайджест в Telegram
```

Боевой запуск по утрам на VPS — `--source hh --send` через systemd-timer (см. `docs/vps_setup.md`).

## Скоринг релевантности

`src/relevance.py` — ядро. На вход вакансия (заголовок + описание + зарплата),
на выход скор 0..100 и объяснение (совпавшие навыки, пропуски, red flags, зарплата).

```bash
python3 src/relevance.py   # демо на трёх примерах вакансий
```

Пороги (в `profile.json`): ≥80 — приоритетный отклик, ≥55 — в дайджест, <40 — пропуск.

## Структура

```
profile/profile.json   # машиночитаемый профиль + веса навыков + параметры поиска
profile/profile.md     # человекочитаемый профиль + что поправить в резюме
resume/master_cco.md   # эталонное резюме (база для адаптаций)
src/relevance.py       # скоринг релевантности вакансии профилю
src/sources.py         # источники вакансий (sample | hh) с единым интерфейсом
src/pipeline.py        # пайплайн дайджеста: источник → дедуп → скоринг → Telegram
src/notify.py          # отправка в Telegram (stdlib)
data/sample_vacancies.json  # тестовые вакансии для офлайн-прогона
docs/telegram_setup.md # как создать бота и узнать chat_id
docs/vps_setup.md      # РФ-VPS, деплой, авторизация HH, systemd-timer
.env.example           # шаблон секретов (реальный .env — в .gitignore)
```

## Следующие шаги

1. **Кандидат:** создать Telegram-бота (`docs/telegram_setup.md`) и поднять VPS в РФ
   (`docs/vps_setup.md`); передать токен/chat_id через `.env` (не в репозиторий).
2. **Разработка:** реализовать боевой источник `hh` (эмуляция приложения на VPS) →
   включить `--source hh`.
3. **Фаза 2:** генерация резюме/сопроводительного под вакансию + отклик по подтверждению.
