# findwork — система поиска работы для Павла Скворцова

Цель: автоматизировать поиск работы на позиции **CMO / CCO / Growth**:

1. 🔍 собирать новые вакансии по профилю;
2. 📨 утром присылать дайджест релевантных вакансий в Telegram;
3. 📝 генерировать резюме/сопроводительное под конкретную вакансию;
4. ✅ откликаться на релевантные (с подтверждением или авто — по выбору).

## HH.ru: легальный путь через официальный API (OAuth2)

Изучено по первоисточнику ([OpenAPI HH](https://api.hh.ru/openapi/redoc) + [github.com/hhru/api](https://github.com/hhru/api)),
июнь 2026 — подробно в [docs/hh_api.md](docs/hh_api.md).

Прежняя инфа «API для соискателей закрыт» — из вторичных источников. Первоисточник показывает,
что **официальный путь жив**: регистрируешь приложение на `dev.hh.ru` (работает, HTTP 200), берёшь
`client_id/secret`, получаешь токен и работаешь по API. Мой прежний `403` был из-за **анонимного**
запроса с дата-центрового IP; с токеном поиск работает (без токена — капча).

- **Токен приложения** (`client_credentials`) — для поиска вакансий, без логина.
- **Токен соискателя** (`authorization_code`) — для персонального поиска и **откликов** (`/negotiations`).

> Никакой эмуляции/обхода. Отклики — только после подтверждения кандидата (human-in-the-loop),
> с вежливыми лимитами.

## Решения (зафиксированы с кандидатом)

- **Подход к HH-риску:** полу-авто с подтверждением (бот предлагает → кандидат жмёт «OK»).
- **Хостинг:** свой VPS в РФ (резидентный IP для стабильной работы с HH).
- **Канал:** Telegram-бот (создаём — см. `docs/telegram_setup.md`).
- **Профиль поиска:** CMO / CCO / Growth · 600–900к ₽ · формат неважно · акцент на матчинг релевантности.

## План по фазам

- **Фаза 0 — фундамент** ✅ *(сделано)*
  - Профиль и веса навыков — `profile/profile.json` (+ `profile.md`).
  - Эталонное резюме — `resume/master_cco.md`.
  - Ядро скоринга — `src/relevance.py` (без зависимостей, с демо).
- **Фаза 1 — сбор вакансий + утренний дайджест в Telegram** 🚧 *(пайплайн + легальный источник готовы)*
  - ✅ Пайплайн `src/pipeline.py`: источник → дедуп → скоринг → дайджест в Telegram.
  - ✅ Отправка в Telegram `src/notify.py`; тестовый источник `sample` гоняется офлайн.
  - ✅ Легальный источник `trudvsem` (офиц. открытый API «Работа России», без обхода).
  - ⏳ Боевой источник `hh` (эмуляция приложения) — подключается на VPS (`src/sources.py`).
- **Фаза 2 — авто-отклик под выбранную вакансию** 🚧 *(реализовано, нужен токен приложения)*
  - Ты присылаешь боту ссылку на вакансию → бот создаёт релевантное резюме на основе
    твоих резюме, пишет сопроводительное и сам откликается. Управление: `/pause`, `/resume`,
    `/status`, `/dry`. Серый путь (эмуляция приложения HH) — см. [docs/auto_apply.md](docs/auto_apply.md).
  - Модули: `src/hh_app.py`, `src/tailor.py`, `src/apply.py`, `src/bot.py`.
- **Фаза 3 — расширение охвата и качество** — доп. источники, LLM-доскоринг, дашборд.

## Запуск

```bash
python3 src/relevance.py                          # демо скоринга
python3 src/pipeline.py --source sample --dry-run  # дайджест на тестовых вакансиях (без отправки)
python3 src/pipeline.py --source sample --send     # отправить тестовый дайджест в Telegram
```

Боевой запуск по утрам на VPS — `--source hh --send` через systemd-timer (см. `docs/vps_setup.md`).

## Скоринг релевантности

`src/relevance.py` — ядро. На вход вакансия (заголовок + описание + зарплата),
на выход скор 0..100 и объяснение (совпавшие навыки, пропуски, red flags, зарплата).

```bash
python3 src/relevance.py   # демо на трёх примерах вакансий
```

Пороги (в `profile.json`): ≥80 — приоритетный отклик, ≥55 — в дайджест, <40 — пропуск.

## Следующие шаги

1. **Кандидат:** создать Telegram-бота (`docs/telegram_setup.md`) и поднять VPS в РФ
   (`docs/vps_setup.md`); передать токен/chat_id через `.env` (не в репозиторий).
2. **Кандидат:** авторизоваться под приложение HH (`hh-applicant-tool authorize`) —
   это включит авто-отклик (`docs/auto_apply.md`); по желанию добавить `ANTHROPIC_API_KEY`.
3. **Запуск авто-отклика:** поднять бота (`python3 src/bot.py`) и слать ему ссылки на вакансии;
   управлять паузой через `/pause` / `/resume`.
