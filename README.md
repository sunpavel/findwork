# findwork — система поиска работы для Павла Скворцова

Цель: автоматизировать поиск работы на позиции **CMO / CCO / Growth**:

1. 🔍 собирать новые вакансии по профилю;
2. 📨 утром присылать дайджест релевантных вакансий в Telegram;
3. 📝 генерировать резюме/сопроводительное под конкретную вакансию;
4. ✅ откликаться на релевантные (с подтверждением или авто — по выбору).

## ⚠️ Важная реальность: HH.ru закрыл публичный API для соискателей (15.12.2025)

Проверено эмпирически (июнь 2026): запрос к `api.hh.ru/vacancies` отдаёт `403 forbidden`
даже с корректным `User-Agent`. Официальный путь (OAuth-приложение → поиск/резюме/отклики)
для соискательских сервисов больше недоступен.

Рабочие, но **«серые»** обходные пути (оба нарушают ToS HH, есть риск блокировки аккаунта):

- **Эмуляция официального Android-приложения HH** (как `s3rgeym/hh-applicant-tool`).
- **Эмуляция браузера** (Playwright: логин по SMS, клики, капча вручную).

> Поэтому массовый автоотклик и автосоздание резюме на HH — это обход защиты с реальным
> риском бана. Подход к риску выбирает кандидат (см. «Открытые решения»). По умолчанию
> рекомендуется human-in-the-loop: бот предлагает — кандидат подтверждает.

## План по фазам

- **Фаза 0 — фундамент** ✅ *(сделано)*
  - Структурированный профиль и веса навыков — `profile/profile.json` (+ `profile.md`).
  - Эталонное резюме — `resume/master_cco.md`.
  - Ядро скоринга релевантности — `src/relevance.py` (без зависимостей, с демо).
- **Фаза 1 — сбор вакансий + утренний дайджест в Telegram** (низкий риск) — *далее*
  - Источник вакансий (выбрать: эмуляция HH-приложения / парсер / Telegram-каналы / др.).
  - Дедуп (хранить виденные id), скоринг (`relevance.py`), опц. LLM-доскоринг.
  - Cron утром → топ-вакансии в Telegram со ссылкой и «почему подходит».
- **Фаза 2 — полу-автоотклик с подтверждением** (средний риск)
  - Кнопки в боте: «Резюме под вакансию» (LLM-адаптация) / «Откликнуться» / «Пропустить».
- **Фаза 3 — полный автоотклик по порогу** (макс. риск) — только по явному согласию.

## Скоринг релевантности

`src/relevance.py` — ядро. На вход вакансия (заголовок + описание + зарплата),
на выход скор 0..100 и объяснение (совпавшие навыки, пропуски, red flags, зарплата).

```bash
python3 src/relevance.py   # демо на трёх примерах вакансий
```

Пороги (в `profile.json`): ≥80 — приоритетный отклик, ≥55 — в дайджест, <40 — пропуск.

resume/master_cco.md   # эталонное резюме (база для адаптаций)
